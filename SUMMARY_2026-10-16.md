## 3. Logika Perhitungan & Sistem Penilaian CS (Scoring System)

Sistem penilaian dirancang agar **objektif, adil, transparan, dan tidak hanya melihat kuantitas tiket semata**.

### A. Formula Tiga Pilar Utama (Bobot 100%)

$$\mathbf{\text{Nilai Akhir}} = (\mathbf{\text{Nilai Tiket}} \times 30\%) + (\mathbf{\text{Nilai Soft Skill}} \times 40\%) + (\mathbf{\text{Kepuasan Klien}} \times 30\%)$$

```
  ┌────────────────────────────────────────────────────────────────────────┐
  │                      KOMPOSISI NILAI AKHIR (100%)                      │
  ├───────────────────────┬────────────────────────┬───────────────────────┤
  │   Nilai Tiket (30%)   │ Nilai Soft Skill (40%) │ Kepuasan Klien (30%)  │
  │  (Produktivitas &     │ (Komunikasi, Sikap,    │  (Rating Bintang CSAT │
  │   Tingkat Kesulitan)  │  Kecepatan, Kerjasama) │   Ulasan Pelanggan)   │
  └───────────────────────┴────────────────────────┴───────────────────────┘
```

---

### B. Rincian Cara Kerja Masing-Masing Pilar

#### 1. Nilai Tiket (Bobot 30%)
- **Skor Mentah per Modul**: Setiap modul sistem Probus memiliki bobot kesulitan (60–90 poin).
  $$\text{Skor Baris} = \text{Bobot Modul} \times \text{Jumlah Tiket Selesai}$$
- **Total Skor Mentah CS (`raw_ticket_score`)**:
  $$\text{Raw Ticket Score} = \sum (\text{Bobot Modul} \times \text{Jumlah Tiket Selesai})$$
- **Normalisasi Relatif Tim (Skala 0–100) (`ticket_score`)**:
  Sistem mencari peraih poin tertinggi di tim pada bulan tersebut (`max_ticket_score`):
  $$\text{Nilai Tiket} = \left(\frac{\text{Raw Ticket Score CS}}{\text{Max Raw Score Tim}}\right) \times 100$$
  *(CS peraih poin tertinggi otomatis memperoleh nilai sempurna **100**, CS lain dinilai secara proporsional).*
- **Porsi Kontribusi Tim (%) (`team_portion`)**:
  $$\text{Porsi Kontribusi Tim} = \left(\frac{\text{Raw Ticket Score CS}}{\sum \text{Total Raw Score Tim}}\right) \times 100\%$$

#### 2. Nilai Soft Skill (Bobot 40%)
Atasan mengevaluasi 5 aspek kinerja skala bulat 1 sampai 5 bintang (Maksimal $5 \times 5 = 25$ poin):
1. **Komunikasi**: Kejelasan, keramahan, dan kesantunan penyampaian solusi.
2. **Kualitas Solusi**: Ketepatan analisa masalah tanpa komplain berulang.
3. **Kecepatan Respon**: Ketanggapan awal saat menerima tiket.
4. **Sikap & Profesionalisme**: Etika kerja, kesabaran, dan kedisiplinan.
5. **Kerjasama Tim**: Inisiatif membantu mendampingi/alih tiket (*takeover*) rekan CS lain.

$$\text{Nilai Soft Skill (0--100)} = \left(\frac{\text{Skor 1} + \text{Skor 2} + \text{Skor 3} + \text{Skor 4} + \text{Skor 5}}{25}\right) \times 100$$

#### 3. Nilai Kepuasan Klien / CSAT (Bobot 30%)
Diambil dari rata-rata ulasan bintang klien pada tiket yang ditangani (skala 1.0 s/d 5.0 bintang):
$$\text{Nilai Kepuasan Klien (0--100)} = \left(\frac{\text{Rating Bintang}}{5.0}\right) \times 100$$

### D. Contoh Simulasi Perhitungan Riil (Studi Kasus Jaden)

Misalkan akun CS **Jaden** dievaluasi untuk periode **Oktober 2026**:

1. **Perhitungan Tiket Modul**:
   - Modul *Accounting* (Bobot 90): 3 tiket $= 3 \times 90 = 270$
   - Modul *Front Desk* (Bobot 85): 4 tiket $= 4 \times 85 = 340$
   - Modul *POS* (Bobot 80): 3 tiket $= 3 \times 80 = 240$
   - Modul *General* (Bobot 60): 3 tiket $= 3 \times 60 = 180$
   - Total Raw Score Jaden $= 270 + 340 + 240 + 180 = \mathbf{1.030 \text{ poin}}$.
   - Peraih poin tertinggi di tim bulan Oktober adalah Jaden ($1.030 \text{ poin}$).
   - Total poin seluruh tim $= 3.100 \text{ poin}$.
   - **Nilai Tiket Jaden**: $(1.030 / 1.030) \times 100 = \mathbf{100.00}$
   - **Porsi Kontribusi Tim**: $(1.030 / 3.100) \times 100\% = \mathbf{33.2\%}$

2. **Perhitungan Soft Skill**:
   - Nilai: Komunikasi (5), Kualitas (4), Kecepatan (5), Sikap (5), Kerjasama (4) $\rightarrow$ Total: 23 poin.
   - **Nilai Soft Skill Jaden**: $(23 / 25) \times 100 = \mathbf{92.00}$

3. **Perhitungan Kepuasan Klien**:
   - Rata-rata bintang klien: **4.8 bintang**.
   - **Nilai Kepuasan Jaden**: $(4.8 / 5.0) \times 100 = \mathbf{96.00}$

4. **Kalkulasi Nilai Akhir**:
   - Porsi Tiket (30%): $100.00 \times 0.30 = \mathbf{30.00}$
   - Porsi Soft Skill (40%): $92.00 \times 0.40 = \mathbf{36.80}$
   - Porsi Kepuasan (30%): $96.00 \times 0.30 = \mathbf{28.80}$
   - **Total Nilai Akhir**: $30.00 + 36.80 + 28.80 = \mathbf{95.60}$
   - **Predikat**: 🟢 **Sangat Baik**

### J. Penyeragaman Ukuran Dropdown Filter & Perbaikan UI (Daftar Request, My Request, Inbox, Daftar Tiket)
- **Masalah**: Tombol dropdown filter (*Semua System* & *Semua Module*) pada toolbar Daftar Request dan My Request sebelumnya memiliki lebar yang berbeda dan teks opsi sempat menimpa ikon panah dropdown akibat penggunaan inline CSS SVG dan padding kanan sempit.

  1. Menyeragamkan ukuran container kedua dropdown menjadi **`w-40 sm:w-48`** sehingga memiliki ukuran 100% simetris dan seimbang (160px di mobile, 192px di desktop/tablet).
  2. Menambahkan kelas **`truncate`** sehingga opsi yang memiliki teks panjang akan terpotong rapi dengan elipsis (`...`) tanpa mengubah ukuran tombol.
  3. Membungkus dropdown dalam kontainer `.relative` dengan ikon chevron FontAwesome `<i class="fa-solid fa-chevron-down ..."></i>` dan padding aman `pl-3.5 sm:pl-4 pr-9 sm:pr-10` sehingga teks tidak akan pernah menabrak ikon panah.
  4. Penyeragaman styling dan ukuran seragam juga diterapkan pada dropdown di [`resources/views/inbox.blade.php`](file:///e:/Project_Magang/Probus-Implementator-2026/resources/views/inbox.blade.php) (`w-40 sm:w-48`) dan [`resources/views/daftartiket.blade.php`](file:///e:/Project_Magang/Probus-Implementator-2026/resources/views/daftartiket.blade.php) (`w-36 sm:w-44`).
